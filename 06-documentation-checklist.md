# 6. Documentation checklist

Every mini project and capstone README needs all of these. Weekly Builds need at least the title and description, the
setup instructions and the screenshots or links.

- [ ] **Title** and a one-line description.
- [ ] **Problem statement** and key features.
- [ ] **Technology stack** and an **architecture diagram**.
- [ ] **Setup instructions**: prerequisites, install, environment variables (via `.env.example`), how to run.
- [ ] **Screenshots or a GIF**, plus the **live URL** and **demo video** link where they exist.
- [ ] **Folder structure** overview and **API reference** (where relevant).
- [ ] **Team members and their contributions**, and **future scope**.

A good test: could a classmate who has never seen your project run it from the README alone, in 10 minutes?

# 4. Using templates

Some projects start from an RMS template: a repository in the [rms-careers](https://github.com/rms-careers)
organisation with starter files and folders.

## Creating your repo from a template

1. Open the template link in your project brief.
2. Click **Use this template → Create a new repository**.
3. Owner: **your own account**. Name: as given in [Repository rules](03-repository-rules.md). Visibility: **Public**.
4. Clone your new repo and start working:

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
```

Your repo is fully yours; it is not linked to the template.

## Template versions

Templates are tagged with the syllabus version, for example `v1.0`. Your brief links to the version your batch uses.
If a template is fixed during your batch, your tutor will tell you what changed and how to apply it. Usually you copy
the fixed file by hand. You never need to "sync" with the template.

## Something wrong in a template?

Open an issue in the template repo with the **Template problem** form. Do not include your solution.

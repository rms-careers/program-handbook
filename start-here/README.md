# Start here: GitHub from zero

**Never used GitHub before? This guide is for you.** It assumes you know nothing about Git or GitHub. Follow the steps in
order and by the end you will have:

- a GitHub account,
- Git working on your computer,
- your own `rms-weekly-labs` repository, created from the RMS Careers template,
- your first piece of work saved to GitHub and submitted to your tutor.

Set aside **about 90 minutes**, ideally before your first Week 1 session. If you get stuck, check
[Troubleshooting](troubleshooting.md), then ask your tutor. Getting stuck on setup is normal and nothing to worry about.

## The steps

| Step | What you do | Time |
|---|---|---|
| [1. What Git and GitHub are](01-what-is-git-and-github.md) | Understand the idea before clicking anything | 10 min |
| [2. Create your GitHub account](02-create-your-github-account.md) | Sign up, choose a good username, secure the account | 15 min |
| [3. Set up your computer](03-set-up-your-computer.md) | Install VS Code and Git, tell Git who you are | 20 min |
| [4. Create your first repository](04-create-your-first-repository.md) | Copy the template into your account and onto your computer | 15 min |
| [5. Save and upload your work](05-save-and-upload-your-work.md) | The everyday loop: edit, commit, push | 15 min |
| [6. Submit your work](06-submit-your-work.md) | Hand the repo to your tutor through the RMS student portal | 10 min |
| [7. Other projects and team work](07-other-projects-and-team-work.md) | New repos, teammates, shared lab computers | Read in Week 3 |

Two reference pages you can come back to at any time:
- [Troubleshooting](troubleshooting.md): common error messages and how to fix them.
- [Glossary](glossary.md): every Git and GitHub word used in this program, in plain English.

## The whole picture in one diagram

```text
  github.com/rms-careers                  github.com/YOUR-USERNAME             student.rms-careers.com
  (RMS Careers organisation)              (your own account)                   (RMS student portal)
 ┌────────────────────────────┐   copy   ┌────────────────────────────┐ link ┌──────────────────────────┐
 │ template-weekly-labs       │ ───────▶ │ rms-weekly-labs            │ ───▶ │ Batch Workspace          │
 │ program-handbook (this)    │  once    │ (your repository)          │      │ → Week 1 → project       │
 └────────────────────────────┘          └────────────▲───────────────┘      │ → paste repo link        │
                                                      │ push (upload)        │ → tutor reviews it       │
                                                      │                      └──────────────────────────┘
                                         ┌────────────┴───────────────┐
                                         │ your computer              │
                                         │ edit → save → commit       │
                                         └────────────────────────────┘
```

- **RMS Careers** keeps the starting files (templates) and this handbook in the `rms-careers` organisation. You only
  read and copy from there. You never upload work to it.
- **You** keep all your work in **your own** GitHub account. It is yours forever and becomes your portfolio.
- **Your tutor** sees your work when you paste the repository link into the RMS student portal.

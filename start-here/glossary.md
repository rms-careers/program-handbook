# Glossary

[← Start here](README.md)

Every Git and GitHub word used in this program, in plain English, in alphabetical order.

| Word | Meaning |
|---|---|
| **Branch** | A separate line of work inside a repository. `main` is the main branch. In team work, each person builds a feature on their own branch, then merges it into `main`. |
| **Clone** | Download a repository from GitHub to your computer for the first time, together with its history and its link back to GitHub. |
| **Collaborator** | A person the owner has given permission to push to their repository. Teammates are collaborators. |
| **Commit** | A save point in a repository's history, with a message describing the change. Also the verb: "commit your changes". |
| **Commit message** | The short description you give a commit, such as `Add simple interest program`. |
| **Conflict (merge conflict)** | Two people changed the same lines, so Git cannot combine them automatically and asks you to choose. |
| **Contribution graph** | The green squares on your GitHub profile showing the days you made commits. Recruiters look at it. |
| **`.env` file** | A file holding secrets (passwords, API keys) for a project. Never commit it; commit a `.env.example` with fake values instead. |
| **Fork** | A copy of someone else's repository under your account, used to propose changes to projects you don't belong to. In this program, use collaborators instead. |
| **Git** | The program on your computer that records the history of your project. |
| **GitHub** | The website (github.com) that stores Git repositories online so you can back them up and share them. |
| **`.gitignore`** | A file listing what Git should never track or upload, such as `.env` files and `__pycache__` folders. |
| **Main (`main`)** | The default branch of a repository. Your finished work ends up here. |
| **Merge** | Combine the commits from one branch into another, for example a feature branch into `main`. |
| **Organisation** | A shared GitHub account for a group. `rms-careers` is RMS Careers' organisation and holds the templates and this handbook. |
| **Origin** | Git's nickname for the GitHub copy of your repository (the place you cloned from). `git push` sends commits to origin. |
| **Public / Private** | Public repos can be viewed by anyone with the link; private ones only by people you invite. Program repos are public by default. |
| **Pull** | Download new commits from GitHub into your computer's copy. |
| **Pull request (PR)** | A request on GitHub to merge a branch into `main`, where teammates review the change before it is merged. |
| **Push** | Upload your new commits from your computer to GitHub. |
| **README** | The `README.md` file shown on a repository's front page. It explains what the project is and how to run it. |
| **Remote** | A copy of the repository somewhere else, usually on GitHub. See *origin*. |
| **Repository (repo)** | A project folder tracked by Git: the files plus their full history. |
| **Rotate (a secret)** | Replace a leaked password or key with a new one and cancel the old one. |
| **Staging (`git add`)** | Choosing which changes go into the next commit. |
| **Tag** | A permanent label on one commit, such as `v1.0`. Templates are tagged so every batch uses a fixed version. |
| **Template repository** | A repository you copy with **Use this template** to start your own project with ready-made files. |
| **Terminal** | A window where you type commands. In this program, the one inside VS Code. |
| **Topic** | A label on a repository, such as `rms-careers`, that makes it easy to find. |
| **Two-factor authentication (2FA)** | Signing in needs your password plus a code from your phone. Protects your account. |
| **Working tree** | The files in your repository folder as they are right now, including changes you haven't committed yet. |
